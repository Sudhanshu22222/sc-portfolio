## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server (port 5173)
npm run dev

# 3. Build for production (outputs to dist/)
npm run build

# 4. Preview production build locally
npm run preview
```

## 🚀 One-Click Deployment

### Option A: Deploy to Vercel (Recommended)
1. Push this repository to your GitHub account (`https://github.com/Sudhanshu22222/sc-portfolio`).
2. Go to [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New Project"** -> **Import** your repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **"Deploy"**. Your live URL will be ready in ~30 seconds!

### Option B: Deploy to Netlify
1. Push this repository to your GitHub account.
2. Go to [netlify.com](https://netlify.com) and log in with GitHub.
3. Click **"Add new site"** -> **"Import an existing project"**.
4. Select your GitHub repository. Netlify automatically reads `netlify.toml`.
5. Click **"Deploy site"**.

### Option C: Deploy to Firebase Hosting
1. Install tools: `npm install -g firebase-tools`
2. Authenticate: `firebase login`
3. Build project: `npm run build`
4. Deploy: `firebase deploy --only hosting`
